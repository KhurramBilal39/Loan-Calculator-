Loan EMI Calculator - flat package (no folders)

All 12 files go in ONE place. Upload every file to the top level of your GitHub repo:
index.html, privacy.html, sw.js, manifest.webmanifest, store-listing.txt,
icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon-180.png,
appstore-icon-1024.png, playstore-icon-512.png

How to upload on GitHub (works on phone and computer):
1. Unzip this file first. Do not upload the zip itself.
2. In your repo press Add file > Upload files.
3. Select ALL the unzipped files together, wait until all show in the list, press Commit changes.
4. Wait 1-2 minutes, then open  https://khurrambilal39.github.io/EMI-Calculator-/icon-192.png  in your browser. You must see the icon image. If you do, run PWABuilder again.
5. Before this, open privacy.html and replace [add your email address here].
